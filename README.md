# U.S. Job Market Analysis

## Project Overview
This project analyzes U.S. employment and annual wage data to understand job market trends, identify high-paying occupations, and compare employment levels across different careers.

## Tools Used
- Microsoft Excel — Data cleaning and preparation
- Tableau — Data visualization and interactive dashboard

## Dataset
- 767 U.S. occupational records
- Employment and annual wage information

## Questions Answered
1. Which occupations have the highest annual median salaries?
2. Which occupations have the highest employment levels?
3. What is the relationship between employment and annual wages?

## Project Process
1. Cleaned and prepared the dataset using Excel.
2. Analyzed employment and salary information.
3. Created three Tableau visualizations.
4. Combined the visualizations into an interactive dashboard.

## Key Findings
- Pediatric Surgeons had the highest annual median wage in the analyzed dataset, at $559,030.
- Home Health and Personal Care Aides represented approximately 4.3 million jobs.
- Employment levels and annual wages vary significantly across occupations.
